## Rules applied in the extension

1. Demos and tests use fictional towers only. No non-public tower coordinates go into new outputs.
2. Every value keeps its `evidence_type`. Allowed values are `measured`, `third_party_observed`, `operator_supplied`, `modeled_proxy`, `synthetic`, `assumption` and `missing`.
3. `measured`, `third_party_observed` and `operator_supplied` values are rejected unless they have a `source` and an `as_of_date`.
4. Service-population proxies are never summed across sites, because no coverage-union method is implemented.
5. Attribution to ASEAN GeoAI Fusion 2026 / HACK-ID-068 is preserved. AI coding assistance (Claude Code) is disclosed in the README.
